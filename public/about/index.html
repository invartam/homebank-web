HomeBank Web

Manage your HomeBank wallet in a personal finance PWA, with transaction editing, balance history and financial forecasting.

Open the applicationSource and user guideRelease 0.2.2

Your HomeBank file, on desktop or mobile

Open a HomeBank XHB file locally, or configure optional Google Drive synchronization. Review accounts, add expenses and income, manage linked transfers and reconcile transactions. The interface adapts to desktop and mobile screens, with light and dark themes.

HomeBank Web is a separate application compatible with the HomeBank file format. It is not a direct bank connection service.

Understand your balance and plan ahead

View balance history and projections, scheduled transactions and forecasts before the next salary or up to a selected date. Salary detection can be estimated; forecasts are projections, not guaranteed future balances. Consult the user guide for the calculation rules and currency limitations.

Start with a backup

  1. Keep a backup of your wallet.
  2. Open the application in a browser and choose a local XHB file, or follow the optional Drive setup guide.
  3. Read the user guide before editing or synchronizing.

Once the application and wallet have loaded, offline use is possible; later synchronization depends on connectivity and Google authentication.

Scope and limitations

Scheduled transactions are read-only. Split-transaction editing and synchronization-conflict resolution are not available. This page contains only public project information; it does not load wallet data or authenticate to Google Drive.
